HOW IT WORKS

Four steps, one right-click

No dashboard to open, no copy-pasting a job description into a chat window. The whole flow happens on the page you're already reading.

01

Browse any posting

Bespoke pulls the title, company and description straight from LinkedIn's structured data — or has your model read the page on any other job board.

02

Right-click → Generate

Confirm the details it found in a small dialog. Nothing leaves the page until you say go.

03

Download both documents

A resume and a cover letter, written in parallel against that specific description, plus a match score. Markdown or PDF.

04

Track what happens next

Save the application and move it from Applied through interviews to Offer, with notes, tags and prep guides.

FEATURES

The whole application, not just the resume

Resume & cover letter

Written in parallel, each one weighted toward the skills that posting actually asks for.

Smart job scraping

JSON-LD and CSS selectors on LinkedIn; an LLM pass over raw page text everywhere else.

Profile match score

A 0–100 score with strengths, gaps and concrete suggestions for closing them.

Application tracker

Saved → Applied → HR → Technical → Offer, with notes and tags at every stage.

Interview prep

A focused technical guide per role: key technologies, likely questions, deep-dive topics.

Analytics

Applications by status, conversion rates and trends over time.

PDF export

Download either document as PDF straight from the dialog.

Drive sync

Profile, settings and applications back up to your own Drive app folder.

PRIVACY

There is no server to trust.

Bespoke has no backend of its own. Your profile sits in browser storage and travels only to the endpoint you configured.

Local-first storage

Your profile, settings and applications live in the browser. Drive sync is opt-in and uses your own app folder.

Zero telemetry

No pixels, no analytics, no crash reporting. Nothing about your job search is measured.

Auditable

MIT-licensed on GitHub. Read the network calls yourself — there are exactly as many as we claim.
